## Inspection Summary

The wireframe is a long-form authority homepage with these major blocks:

1. floating rounded header with logo, nav links, and social icons
2. oversized dark hero panel with split headline, supporting copy, and two CTAs
3. offer/program card grid with three dark cards and arrow actions
4. centered quote/testimonial proof block
5. authority/bio area with large media panel, metric grid, and bio card
6. logo strip for client/company proof
7. horizontal testimonial/video carousel
8. lead magnet/download opt-in section with form
9. blog/news preview section with featured and secondary posts
10. final CTA band
11. oversized footer with social icons, large name/brand wordmark, nav, copyright, and legal links

The first implementation should focus on reusable section families and starter-safe example data:

- Navigation/Header
- Hero
- Offer/Programs
- Quote Proof
- Authority/Bio
- Logo Strip
- Testimonials Rail
- Lead Magnet
- Blog Preview
- CTA
- Footer

Existing starter sections can cover the hero, service/offer cards, and a baseline testimonial area, but the wireframe requires new section families and richer variants before the homepage can match the layout cleanly.

## Suggested Build Order

1. Header and Footer primitives/sections.
2. CTA and Logo Strip sections.
3. Offer/Programs section variant using the existing services model if possible.
4. Authority/Bio section with metrics and media placeholder.
5. Lead Magnet section with form fields.
6. Blog Preview section.
7. Testimonials rail/video-card variant.
8. Home page template composition.
