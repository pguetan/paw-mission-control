# PROMOTION-CHECKLIST.md

## Purpose

Use this checklist before promoting any pattern into the future registry or back into the starter.

## Promotion Criteria

- [ ] Solves a repeatable use case.
- [ ] Not tied to one client.
- [ ] Uses starter tokens and primitives.
- [ ] Has typed props or schema.
- [ ] Has example data.
- [ ] Has usage documentation.
- [ ] Declares dependencies.
- [ ] Has a clear use-case name.
- [ ] Checked on mobile, tablet, and desktop.
- [ ] Passes relevant validation.

## Remove Before Promotion

- [ ] Client copy
- [ ] Client images
- [ ] Custom client fonts
- [ ] Client-specific brand colors
- [ ] Route-specific hacks
- [ ] One-off layout exceptions

## Promotion Decision

Record:

- source repo
- reason for promotion
- target repo
- affected files
- compatibility notes
- follow-up tasks
