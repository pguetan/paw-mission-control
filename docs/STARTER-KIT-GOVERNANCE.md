# STARTER-KIT-GOVERNANCE.md

## Purpose

Define how mission control manages `paw-starter-kit`.

## Starter Role

The starter kit is the reusable runtime foundation.

It should contain:

- app scaffold
- tokens
- primitives
- starter sections
- brand-neutral example content
- sanitized starter docs
- validation scripts
- CI
- base SEO

It should not become:

- a client website
- an internal strategy archive
- a registry dumping ground
- a place for client-specific experiments

## Change Requirements

Starter changes must:

- improve future projects
- preserve brand neutrality
- avoid client-specific copy/assets
- update docs when structure or behavior changes
- update inventories when components or sections change
- pass `pnpm check`

## Starter Tracker

The current starter tracker is:

```txt
systems/paw-starter-kit.md
```

Keep it updated when the starter phase, roadmap, or release state changes.
